# ウィンドウマン

Windows 11 のショートカットキーを覚えるための正義のヒーローです。ピンチの時には Alt 2 回で駆け付けます。

「ウィンドウを左半分に寄せたい」のように、やりたいことから操作を探せます。動きを見て、実際にキーを押して覚えます。操作を代わりに実行することはしません。使いこなして、このアプリが要らなくなることを目指しています。

ウィンドウマンは、「OS やアプリごとのヒーローが操作を教える」構想 HeroesStation の、最初のヒーローです。

## はじめかた

1. `ウィンドウマン.exe` を、好きなフォルダー（デスクトップやドキュメントなど）に移します。インストールは要りません。
2. ダブルクリックで起動します。画面の中央に説明が出ます。「わかった」で閉じると、後ろで待っています。
3. **Alt キーだけを、すばやく 2 回押します。** マウスカーソルの近くにパネルが出ます。

ダウンロードした exe を初めて開くとき、Windows が「Windows によって PC が保護されました」と出すことがあります。このアプリに電子署名をしていないためです。「詳細情報」→「実行」で起動できます。

## 使いかた

| やりたいこと | 方法 |
| --- | --- |
| 操作を探す | パネルが出たら、そのまま文字を打つ（例：「分割」「コピー」「ctrl」） |
| 種類で絞る | 上のタブ（ウィンドウ・ファイル操作・テキスト編集 など）。入りきらないタブは、タブの列を横にドラッグ |
| 詳しく見る | 項目をクリック、または ↑ ↓ で選んで Enter |
| 練習する | 詳細を開くと、元の作業ウィンドウに戻ります。そのままキーを押すと、押したキーに色が付きます |
| 一覧に戻る | 詳細の左上の「‹ 戻る」 |
| 閉じる | ×、もう一度 Alt 2 回、一覧で Esc、またはパネルの外をクリック（エクスプローラーやデスクトップから呼び出したときは、ファイルを選べるように、外をクリックしても閉じません） |
| 気に入った操作をまとめる | ☆ を押すと ★ タブに入ります |
| 覚えた操作を外す | 「もう覚えた」。「覚えたものも表示」で戻せます |
| キーを押しても反応しない | 右下の「→反応しない場合は？」。日本語入力や Caps Lock などの状態と、確かめることが出ます |

はじめの設定では、使っているアプリに合わせて最初のタブが開きます（メモ帳や VS Code ならテキスト編集、エクスプローラーやデスクトップならファイル操作）。

## 設定

一覧の右上の ⚙ から開きます。

- **表示の優先度**：出すタブを選んだり、並べ替えたりできます。
- **呼び出したときのタブ**：使っているアプリに合わせて、最初に開くタブを選ぶかどうか。
- **呼び出し方**：Alt 2 回のほかに、好きなキーの組み合わせ（例：Ctrl + Shift + F11）でも呼び出せるようにできます。

設定は `ウィンドウマン.exe` と同じフォルダーの `settings.json` に保存されます。exe を別のフォルダーに移すときは、`settings.json` も一緒に移してください。Program Files のような書き込めないフォルダーに置くと、設定を保存できません。

## 終わりかた・消しかた

- **終わる**：パネルの ⚙ を開き、いちばん下の「バイバイ」を押します。パネルを出せないときは、タスクマネージャー（Ctrl + Shift + Esc）の「プロセス」で「ウィンドウマン」を選び、「タスクを終了」します。
- **消す**：終わらせてから、次の 2 つを削除します。
  - `ウィンドウマン.exe` と、同じフォルダーの `settings.json`
  - `%LOCALAPPDATA%\com.heroesstation.app` フォルダー。画面の表示に使う Windows の部品（WebView2）が、起動したときに作る作業用のデータです。動いている間は消せないので、先に終わらせてください。

## 読み取る情報

このアプリが読み取るのは、次のものだけです。

- 呼び出しのための Alt キーの状態と、最後にキーやマウスを操作した時刻（どのキーかは読みません）
- 詳細を開いている間、表示している操作のキーが押されたかどうか
- Caps Lock・Num Lock・Scroll Lock がオンかどうか（ロックの操作の詳細と「反応しない場合は？」を開いている間）
- 日本語入力がオンかどうか（「反応しない場合は？」を開いている間）
- 呼び出したときに前面にあったウィンドウのタイトルと、エクスプローラーやデスクトップで選んでいるファイルの名前（パネルの上に表示するため）
- パネルの検索欄に打った文字と、設定で呼び出しのキーを決めるときに押したキー

どれも保存せず、どこにも送りません。保存するのは、お気に入り・もう覚えた操作・設定だけです。このアプリには、インターネットへ接続する処理がありません。
