# HeroesStation

Windows 11 の操作を覚えるための、正義のヒーローたちです。ピンチの時には Alt 2 回で駆け付けます。

- **ウィンドウマン**：ショートカットキーを教えます。「ウィンドウを左半分に寄せたい」のように、やりたいことから操作を探せます。動きを見て、実際にキーを押して覚えます。
- **コマンドマン**：コマンドプロンプトと PowerShell のコマンドを教えます。やりたいことから探して、オプションを選ぶと、そのコマンドの文字列ができます。コピーして、自分で貼って実行します。

どちらも、操作を代わりに実行することはしません。使いこなして、このアプリが要らなくなることを目指しています。

## はじめかた

1. `HeroesStation.exe` を、好きなフォルダー（デスクトップやドキュメントなど）に移します。インストールは要りません。
2. ダブルクリックで起動します。画面の中央に説明が出ます。「わかった」で閉じると、後ろで待っています。
3. **Alt キーだけを、すばやく 2 回押します。** マウスカーソルの近くにパネルが出ます。

ダウンロードした exe を初めて開くとき、Windows が「Windows によって PC が保護されました」と出すことがあります。このアプリに電子署名をしていないためです。「詳細情報」→「実行」で起動できます。

## 使いかた

| やりたいこと | 方法 |
| --- | --- |
| ヒーローを切り替える | ヘッダーの下の「ウィンドウマン」「コマンドマン」。次に呼び出したときは、最後に選んだヒーローが出ます |
| 操作を探す | パネルが出たら、そのまま文字を打つ（例：「分割」「コピー」「ctrl」） |
| 種類で絞る | 上のタブ（ウィンドウ・ファイル操作・テキスト編集 など）。入りきらないタブは、タブの列を横にドラッグ |
| 詳しく見る | 項目をクリック、または ↑ ↓ で選んで Enter |
| 前後の操作を見る | 詳細でスクロールすると、一覧の順に前後の操作へ移れます |
| 練習する（ウィンドウマン） | 詳細を開くと、元の作業ウィンドウに戻ります。そのままキーを押すと、押したキーに色が付きます |
| コマンドを作る（コマンドマン） | 詳細でオプションを選び、欄に値を入れると、上のコマンドが変わります。「コピー」を押して、コマンドプロンプトや PowerShell に貼ります |
| 一覧に戻る | 詳細の左上の「‹ 戻る」（コマンドマンは Esc でも戻れます） |
| 閉じる | ×、もう一度 Alt 2 回、一覧で Esc、またはパネルの外をクリック（エクスプローラーやデスクトップから呼び出したときは、ファイルを選べるように、外をクリックしても閉じません） |
| 気に入った操作をまとめる | ☆ を押すと ★ タブに入ります |
| どれから覚えるか | 各行の右のアンテナ（3 本＝優先度が高い）。詳細で押すと、自分で変えられます |
| 覚えた操作を外す | 「もう覚えた」。「覚えたものも表示」で戻せます |
| キーを押しても反応しない | 右下の「→反応しない場合は？」。日本語入力や Caps Lock などの状態と、確かめることが出ます |

はじめの設定では、使っているアプリに合わせて最初のタブが開きます（メモ帳や VS Code ならテキスト編集、エクスプローラーやデスクトップならファイル操作）。

## 設定

一覧の右上の ⚙ から開きます。

- **表示の優先度**：出すタブを選んだり、並べ替えたりできます。ヒーローごとに設定します。
- **呼び出したときのタブ**：使っているアプリに合わせて、最初に開くタブを選ぶかどうか。
- **呼び出し方**：Alt 2 回のほかに、好きなキーの組み合わせ（例：Ctrl + Shift + F11）でも呼び出せるようにできます。

設定は `HeroesStation.exe` と同じフォルダーの `settings.json` に保存されます。exe を別のフォルダーに移すときは、`settings.json` も一緒に移してください。Program Files のような書き込めないフォルダーに置くと、設定を保存できません。

## 終わりかた・消しかた

- **終わる**：パネルの ⚙ を開き、いちばん下の「バイバイ」を押します。パネルを出せないときは、タスクマネージャー（Ctrl + Shift + Esc）の「プロセス」で「HeroesStation」を選び、「タスクを終了」します。
- **消す**：終わらせてから、次の 2 つを削除します。
  - `HeroesStation.exe` と、同じフォルダーの `settings.json`
  - `%LOCALAPPDATA%\com.heroesstation.app` フォルダー。画面の表示に使う Windows の部品（WebView2）が、起動したときに作る作業用のデータです。動いている間は消せないので、先に終わらせてください。

## 前の版から移るとき

`ウィンドウマン.exe`（0.1.x）を使っていた方は、次の順で入れ替えてください。お気に入り・もう覚えた操作・設定は、そのまま引き継がれます。

1. いまのウィンドウマンを終わらせます（⚙ → 「バイバイ」）。
2. `HeroesStation.exe` を、`ウィンドウマン.exe` と同じフォルダーに置きます（`settings.json` があるフォルダー）。
3. `ウィンドウマン.exe` を削除し、`HeroesStation.exe` を起動します。

## 読み取る情報

このアプリが読み取るのは、次のものだけです。

- 呼び出しのための Alt キーの状態と、最後にキーやマウスを操作した時刻（どのキーかは読みません）
- 詳細を開いている間、表示している操作のキーが押されたかどうか
- Caps Lock・Num Lock・Scroll Lock がオンかどうか（ロックの操作の詳細と「反応しない場合は？」を開いている間）
- 日本語入力がオンかどうか（「反応しない場合は？」を開いている間）
- 呼び出したときに前面にあったウィンドウのタイトルと、エクスプローラーやデスクトップで選んでいるファイルの名前（パネルの上に表示するため）
- パネルの検索欄に打った文字と、設定で呼び出しのキーを決めるときに押したキー

どれも保存せず、どこにも送りません。「コピー」のボタンを押したときだけ、その文字をクリップボードに書き込みます（クリップボードの中身は読みません）。保存するのは、お気に入り・もう覚えた操作・自分で変えた優先度・設定だけです。このアプリには、インターネットへ接続する処理がありません。
